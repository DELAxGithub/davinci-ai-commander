## 3分でわかる主要機能

1. **Bin の一括作成**：「A-Roll, B-Roll, Audio, SFX の Bin を作って」で一瞬で完了。
2. **タイムライン自動作成**：指定した Bin 内の全素材をタイムラインに一括自動配置。
3. **マーカーの bulk 投入**：位置と指示内容を指定して、タイムライン上にマーカーを自動配置。
4. **バッチ書き出し**：YouTube や ProRes などの複数プリセットを自動適用して一瞬でレンダーキューへ。
5. **コマンド履歴**：`↑` `↓` キーで過去の自動化命令を呼び出し、一瞬でリプレイ。
