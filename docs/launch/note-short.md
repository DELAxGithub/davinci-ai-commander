<!-- Phase 1. 原体験ストーリー -->
## 開発のきっかけ

番組制作の一人法人として、毎週同じ Bin 構造を切り、同じマーカーを打ち、同じレンダープリセットを当てる作業を続けていました。Python で自動化できることは知っていましたが、Resolve Scripting API は癖が強く AI に書かせても一発で動かないことが多く、「自動化したい作業よりコード書きの時間の方が長い」という本末転倒に陥っていました。

そこで、AI に Resolve API の癖を内蔵させた自分用ツールとして組んだのが本アプリです。半年ほど自分の制作現場で使い込んで、bin 量産・マーカー打ち・レンダキュー整理の体感速度が大きく変わったので、製品化に踏み切りました。

## 3分でわかる主要機能

1. **Bin の一括作成**：「A-Roll, B-Roll, Audio, SFX の Bin を作って」で一瞬で完了。
2. **タイムライン自動作成**：指定した Bin 内の全素材をタイムラインに一括自動配置。
3. **マーカーの bulk 投入**：位置と指示内容を指定して、タイムライン上にマーカーを自動配置。
4. **バッチ書き出し**：YouTube や ProRes などの複数プリセットを自動適用して一瞬でレンダーキューへ。
5. **コマンド履歴**：`↑` `↓` キーで過去の自動化命令を呼び出し、一瞬でリプレイ。
