## なぜこのアプリを作ったのか？（開発ストーリー）

このアプリの源流は、私自身の作業環境にあります。番組制作の一人法人として、毎週のように DaVinci Resolve で同じ作業を繰り返していました — 収録回ごとに同じ Bin 構造を切る、指示書通りに何十個のマーカーを打つ、納品先別にレンダープリセットを何度も適用する。動画編集は本来クリエイティブな仕事であるべきなのに、機械的な「仕込み」「片付け」に毎週相当の時間が削られていました。

Python の Resolve Scripting API を使えば自動化できることは知っていました。実際、自分の制作パイプライン用に何本もスクリプトを書いてきました。ただ問題は別のところにあって、**Resolve Scripting API は癖が強く、ChatGPT や Claude に書かせてもなかなか一発で動かない**。AI に試行錯誤させながらスクリプトを書くと「自動化したい作業より、コード書きの時間が長い」という本末転倒に陥っていました。

そこで、「**AI が Resolve API の癖を内蔵した状態で、自然言語の命令を直接 Python に翻訳して実行するアプリ**」を自分用に組みました。半年ほど自分の制作現場で使い込んで、bin 量産・マーカー打ち・レンダキュー整理の体感速度が大きく変わり、「これは同じく Resolve のルーティン作業に消耗している映像エディターにも届くはずだ」という確信が生まれた。それが本アプリ『DaVinci AI Commander』の始まりです。

## アプリ『DaVinci AI Commander』の概要

『DaVinci AI Commander』は、自然な日本語（または英語）で命令するだけで、AI（Google Gemini 2.5 Flash）が DaVinci Resolve を自動操縦するための Python コードを背後で生成・実行してくれる macOS 専用のデスクトップアプリです。

* **製品名**：DaVinci AI Commander
* **価格**：**$19 買い切り**（月額課金ではありません。一度の購入で永続的に利用可能です）
* **動作環境**：macOS 11 (Big Sur) 以降
* **必須要件**：DaVinci Resolve 19 以降 / Google Gemini API Key（ユーザーご自身で取得いただくもの）
* **配布方法**：Gumroad を通じた直接配布（動的コード実行機能を含むため、App Store の審査制限を回避した直販モデルを採用しています）

## なぜ「無料」ではなく「買い切り有料」なのか？（透明性の宣言）

ご指摘の通り、本アプリはユーザー様ご自身の **Google Gemini API Key** を使う設計のため、**開発者側にサーバー維持コストは発生していません**（API の利用料はユーザー様ご自身の従量課金ですが、Gemini 2.5 Flash は非常に安価で、多くの場合は無料枠の範囲内で十分に動作します）。

それでも有料（買い切り）として販売する理由を、正直に書かせてください。

* **DaVinci Resolve / macOS のアップデート追従**：Resolve は毎年メジャーアップデートが入り、Scripting API も小さくない変更が入ります。「動かなくなった」を放置せず、ユーザー様の業務環境で動き続けるツールに保つための継続的な保守時間が必要です。
* **安全設計の維持コスト**：AI が生成したコードを実行前に検査する仕組み、Keychain 連携、署名・公証（notarization）など、業務環境に安心して持ち込めるレベルの品質を維持するための地道な投資です。
* **広告も、データ販売も、サブスクもしない、という宣言**：一人法人のインディー開発者として、ユーザー様から直接対価をいただくシンプルな関係を選びました。買い切りなので、買った後に課金が増えることもありません。
* **「買った人と一緒に育てる」関係に必要な対価**：無料だと「試して放置」になりがちなところ、有料だと使い倒していただけるし、フィードバックの質も格段に上がります。長く一緒に育てるツールにしたい、というのが本音です。

## 機能ツアー：『DaVinci AI Commander』を使う順番ナラティブ

本アプリがどのように日々の編集業務を高速化するか、実際にツールを起動して作業を進める流れに沿ってご紹介します。

### STEP 1：API Key の安全な設定と Resolve への接続
アプリを起動したら、最初に Gemini API キーを入力します。入力されたキーは、macOS 標準の安全なパスワード管理機構「Keychain」に直接保管され、平文のファイルとしてディスクに保存されることはありません。接続ボタンを押すだけで、現在起動している DaVinci Resolve と瞬時にリンクします。

[SCREENSHOT: APIキー設定と Resolve 連携の接続画面]

### STEP 2：Bin（フォルダー構造）の bulk 作成・整理
編集の始まりは素材整理から。「A-Roll、B-Roll、Audio、Music、SFX の Bin を作って」と日本語で話しかけるだけで、AI が構造を理解し、DaVinci Resolve 上に一瞬で Bin を一括生成します。手動で右クリックして新規フォルダーを作って名前を変更する、あの虚無な時間はもう不要です。

[SCREENSHOT: Bin が一括で自動生成される様子]

### STEP 3：タイムラインの自動作成 & クリップ配置
「新しくタイムラインを作って、A-Roll の Bin に入っている素材をすべて並べて」と指示すれば、タイムラインの作成からクリップの一括配置（Append）までを自動で処理します。大まかなカット編集に入る前の「素材を並べる下準備」が秒速で完了します。

[SCREENSHOT: タイムラインが自動作成され、クリップが並ぶ様子]

### STEP 4：インテリジェント・マーカーの一括投入
タイムライン上に「ここにテロップ挿入」「この音声ノイズ除去」といったメモをマーカーとして残す作業も指示できます。「タイムラインの先頭から 10 秒、30 秒、60 秒の位置に、それぞれ指示書のメモを入れた赤いマーカーを配置して」と伝えるだけで、ミリ秒単位で正確な位置にマーカーが並びます。

[SCREENSHOT: マーカーがメモ内容付きでタイムライン上に並んでいる様子]

### STEP 5：レンダーキュー投入 & バッチ書き出し
編集が終わったら、最後はレンダリングです。「YouTube プリセットと ProRes 高画質プリセットでそれぞれレンダーキューに追加して、書き出しを開始して」と指示すれば、複数の書き出し設定を背後で自動適用し、レンダーキューへ一括投入します。

[SCREENSHOT: レンダーキューに複数のジョブが自動で並んでいる様子]

### STEP 6：コマンド履歴（↑↓キー）で定型文を瞬時に再実行
一度実行した素晴らしい自動化命令は、キーボードの `↑` `↓` キーを押すだけで履歴から呼び出せます。毎日行う定番のワークフロー（例：「いつものBin構造を作る」「特定のレンダー設定」）は、プロンプトを再入力することなく一瞬でリプレイ可能です。

[SCREENSHOT: コマンド履歴からプロンプトを呼び出している画面]

## 補助機能リスト（見逃せないこだわり）

メイン機能以外にも、業務利用での実用性を高めるために以下の補助機能を搭載しています。

* **A. AI 生成コードの安全チェック（サンドボックス的バリデーション）**
  AI は強力ですが、稀に意図しないコードを生成するリスクがあります。本アプリは、AI が生成したスクリプトを実行する前に厳格なセキュリティスキャンを行い、システムファイルを書き換えるような危険なパターンが検出された場合は実行を自動でブロックします。
* **B. macOS Keychain 連携による認証情報の完全保護**
  セキュリティ第一の設計として、API キーは暗号化されたシステム領域（Keychain）に預けます。アプリのアンインストールやキーの削除も完全に安全に行えます。
* **C. プロンプトの完全英日対応**
  指示は「bin を作成して」という日本語でも、「create a bin named A-Roll」という英語でも、完全に同様の精度で動作します。
* **D. App Store 制限を受けない Gumroad 直販モデル**
  Apple の厳しい Sandbox 制限（外部アプリの動的コード実行禁止など）のため、App Store での配布は不可能です。Gumroad を通じて安全に署名された `.dmg` / `.app` ファイルをダイレクトに皆様へお届けします。
